# A BIZ SYSTEM

Simple Point-of-Sale (POS) sales screen for Tanzanian businesses.

## Features
- **UZA – Mauzo Mapya** sales interface
- Dark / Light / System theme support
- Product search & cart
- Receipt totals in TZS
- Minimal clean design

## Files
- `a-biz-system-sales.html` – Open this file in any browser to use the sales screen
- `ads.txt` – Template for Google AdSense authorization (upload to website root)

## Usage
1. Open `a-biz-system-sales.html` in Chrome, Firefox, Edge, or Safari
2. Use the theme buttons (Kifaa / Mwanga / Giza) to switch appearance
3. Add products with **+ Ongeza**, then complete the sale

## ads.txt
Upload `ads.txt` to the root of your domains (e.g. `https://yoursite.co.tz/ads.txt`) after replacing the publisher ID with your real Google AdSense ID.
